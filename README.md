# 둥둥 그림 전시회

초등 교실에서 친구나 자유 주제를 그리고, 움직이는 계란 전시와 객관식 퀴즈를 진행하는 웹앱입니다. 화면과 그림 예시는 직접 작성한 HTML, CSS, JavaScript로 구성했습니다.

## GitHub Pages에 올리기

1. ZIP을 풉니다. GitHub에서 `dung-gallery`처럼 새 저장소를 만듭니다.
2. 저장소의 **Add file → Upload files**에서 `index.html`, `style.css`, `app.js`, `roster.js`, `exhibition-scene.js`, `exhibition-tools.js`, `README.md`를 저장소 최상위에 올리고 **Commit changes**를 누릅니다. 기존 사이트를 업데이트할 때도 이 7개 파일을 함께 올립니다.
3. **Settings → Pages**의 **Source**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치 **main**, 폴더 **/(root)**를 선택하고 **Save**를 누릅니다.
5. 배포가 끝나면 **Visit site**로 접속합니다. 예시 주소는 `https://사용자이름.github.io/dung-gallery/`입니다.

[GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 수업 순서

- 먼저 체험하기에서 예시 작품을 보고, 교사 화면과 학생 화면을 오가며 퀴즈를 연습할 수 있습니다.
- 실제 수업은 **우리 반 전시회 열기**에서 학생 명단과 주제, 배정 방식, 점수 모드를 설정합니다. 동명이인은 번호가 붙습니다.
- 교사 화면에 **학생 입장 가능**이 표시되면 QR 또는 초대 링크를 공유합니다. 학생은 자신의 이름을 골라 입장합니다. 별명이나 번호를 명단에 사용할 수 있습니다.
- 그림이 도착하면 움직이는 전시에서 작품을 감상합니다. 교사가 퀴즈를 열면 학생은 **작품 감상** 탭에서 답을 고릅니다. 정답 공개 후 하트를 보낼 수 있습니다.
- 교사 화면의 **수업 백업**으로 작품과 명단을 JSON 파일로 내려받습니다. 홈의 **수업 백업 불러오기**로 다시 열면 새 방 코드가 발급됩니다.

## 엑셀 학생 명렬표

- 설정 화면의 **엑셀 학생 명렬표 불러오기**에서 `.xlsx` 또는 `.xls` 파일을 선택합니다. 파일 크기는 최대 10MB입니다.
- `이름`, `성명`, `학생명` 등의 열을 찾아 학생 명단을 자동 입력하고 저장합니다. 여러 시트가 있으면 이름 열이 있는 시트를 우선 선택합니다.
- 양식이 다르면 **시트**, **학생 이름 열**, **첫 학생이 있는 행**을 직접 선택합니다. 선택할 때마다 명단이 갱신되므로 아래 입력된 이름을 확인하세요.
- 이름 위의 제목과 빈 행을 지원하며, 동명이인도 보존합니다. 학생 명단은 최대 40명이고 이름은 각각 40자까지 입력할 수 있습니다.
- 불러온 이름은 직접 수정할 수 있고 수정 내용도 자동 저장합니다. 다음에 같은 브라우저에서 설정을 열면 마지막 명단이 복원됩니다.
- 저장 대상은 학생 이름 목록입니다. 엑셀 파일은 브라우저 안에서 읽으며, 엑셀의 다른 열을 수업 데이터에 저장하지 않습니다. 저장된 명단은 같은 브라우저에만 적용됩니다.
- 엑셀 읽기에 SheetJS CE 0.20.3을 사용합니다. 이 모듈은 공식 CDN에서 불러오므로 인터넷 연결이 필요합니다. [SheetJS 공식 안내](https://docs.sheetjs.com/docs/getting-started/installation/standalone/)

## 화면 구성

설정 화면은 크림색 배경과 하나의 설정 패널로 구성했습니다. 주제와 배정 방식은 아이콘 카드, 점수 방식은 전환 버튼으로 표시합니다. 문장은 단어 단위로 줄바꿈하며 작은 화면에서는 세로로 배치됩니다.

## 전시 테마와 수업 도구

2026년 11월 11일 원본 사이트의 체험 화면을 다시 열어 전시 테마, 교사 메뉴, 작품 감상, 저장, 발표, 퀴즈 흐름을 확인하고 반영했습니다.

- **둥둥**은 민트색 전시 공간에서 작품이 제자리에서 사뿐사뿐 떠오릅니다.
- **우주 여행**은 어두운 별빛 배경에서 작품이 움직이다 서로 만나면 튕겨 나갑니다.
- **그림 기차**는 작품이 한 줄로 오른쪽에서 왼쪽으로 지나갑니다.
- **회전목마**는 점선 타원 궤도를 따라 작품이 돌아갑니다.
- 속도는 0.5~1.8배로 조절하고, 움직임을 멈추거나 다시 재생할 수 있습니다. 기기의 동작 줄이기 설정을 켜면 이동을 멈춥니다.
- 계란은 WebGL 입체 표면에 그림을 입혀 표시합니다. WebGL을 사용할 수 없는 기기에서는 CSS 계란으로 전시합니다.
- 교사 메뉴는 왼쪽에 배치되고 휴대전화에서는 화면 아래에 표시됩니다. 작품 감상은 액자 카드로 표시합니다.
- **그리기 시간**에서 3분·5분·10분 타이머, 자유 시간, 제출 마감·재개, 수정 그림 허용을 설정할 수 있습니다. 마감 여부는 교사 쪽에서도 검사합니다.
- **그림 저장**은 우리 반 포스터 PNG와 선택 작품 PNG를 지원합니다. 공개 전 작품의 정답과 그린 학생 이름은 이미지에 표시하지 않습니다.
- **작품 발표**는 큰 화면으로 한 작품씩 감상하며 좌우 화살표와 키보드로 이동하고 PNG로 저장합니다.
- 퀴즈에는 응답 진행률, 체험 응답 채우기, 응답 마감, 정답 공개와 다음 퀴즈가 있습니다. 작품을 그린 학생은 자신의 작품 퀴즈에 응답하지 않습니다.
- 작품 관리에서 선택한 미공개 작품을 삭제하거나 모든 작품을 퀴즈 없이 공개할 수 있습니다. 우리 반의 재입장 버튼으로 다른 기기에서 입장할 수 있게 접속을 해제할 수 있습니다.
- 교사·학생 단계별 사용 안내와 그림판 크게 보기, 음악·효과음 설정, 사이트 공유 기능을 추가했습니다.
- 새 방 코드는 6자리입니다. 기존 8자리 방 코드와 이전 수업 백업도 사용할 수 있습니다.

## 확인 범위

브라우저에서 네 테마의 표시·선택·일시정지, 입체 계란 렌더링, PNG 내려받기, 작품 발표, 제출 시간 제한, 체험 퀴즈, 명단 저장·복원과 휴대전화 배치를 확인했습니다. 실제 기기 간 WebRTC 연결과 실제 명렬표 파일 해독은 배포한 사이트에서 확인해야 합니다.

원본의 음악 파일과 오프닝 영상은 확보하지 못했습니다. 음악 설정은 브라우저에서 재생하는 자체 멜로디와 효과음을 사용하며, 원본의 오프닝 영상은 포함되어 있지 않습니다. 원본과 픽셀 단위로 동일한 화면을 검증한 버전은 아닙니다.

## 연결과 저장

- 별도 서버 설치나 빌드는 필요하지 않습니다. 실시간 수업은 PeerJS의 공개 연결 중개 서비스와 WebRTC를 사용합니다. QR은 링크를 브라우저 안에서 변환합니다. 두 라이브러리는 jsDelivr CDN에서 불러옵니다.
- 교사 탭을 닫거나 절전 상태가 되면 연결이 끊길 수 있습니다. 학교 네트워크가 WebRTC나 CDN을 제한할 수 있으므로 수업 전에 같은 네트워크에서 교사와 학생 기기 각 한 대로 입장과 제출을 시험해 보세요.
- 작품과 명단은 교사 브라우저에 보관됩니다. 브라우저 저장 한도에 닿으면 보관이 실패할 수 있으므로 중요한 수업은 JSON 백업을 내려받으세요.
- 초대 코드와 이름 선택으로 참가합니다. 본인 인증 기능은 없으므로 초대 링크는 학급 내에서만 공유하고, 학생 명단이나 백업 JSON은 공개 GitHub 저장소에 올리지 마세요.
- 홈 화면에 추가 기능은 기기 브라우저의 추가 방법을 안내합니다. 서버에 계정이나 작품을 보관하는 구조는 포함하지 않습니다.
